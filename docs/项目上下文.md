## 一、这个项目是什么

**GitPulse** —— 分布式开发者活跃度与项目关注调度系统。
Cloudflare Workers + D1，零第三方业务依赖（纯 Web Crypto 实现 TOTP/PBKDF2/AES-GCM/HMAC）。

核心机制（已全部落地）：多账号托管 → **Web 会话协议登录**（用户名+密码+2FA Secret 算号，
彻底废除 PAT）→ 固化指纹 + CookieJar 持久化 → **静默自愈**（探测 200 执行 / 302 重登 / 失败熔断）
→ 泊松打散的低频活跃动作（star/follow/watch/note 笔记上传）。

**合规底线（不可妥协）**：只守护本人/被明确授权的账号；低频率；绝不用于刷量或伪造他人数据。

1. 改本地 `gitpulse` 代码 → `node --check` 所有动过的文件 → `node scripts/selftest.mjs` 必须 42/42

## 六、踩过的坑（务必记住）

1. **Workers 免费版 10ms CPU**：PBKDF2 迭代不能超过 25k（曾用 200k 导致 setup 直接 500）
2. **Deploy to Cloudflare 按钮**依赖 wrangler.toml 里存在 `database_id` 字段做注入替换——不能注释掉，用占位符 `REPLACE_WITH_DATABASE_ID`
3. **setup-node 的 `cache: npm`** 在无 lockfile 的零依赖项目会直接失败，CI 已移除
4. **本终端 PowerShell 有 PSReadLine 渲染 bug**：长命令输出常被吞/乱码 → 用 `node -e` 写文件再 read_files 读；`>` 重定向是 UTF-16LE 会乱码，用 `Out-File -Encoding utf8`
5. 测试 mock 里别用 `text.includes('ok')` 判断成功——"authenticity_tOKen" 包含 "ok"，曾导致假 session
6. webLogin 是**四步协议**：/login 取token → POST /session → GET /sessions/two-factor/app 取新token → POST otp 回同端点（不要省略 GET 步骤直接复用旧 token）
7. preview.html 和 scripts/preview-app.js 是 check_html.mjs 的生成物，已被 .gitignore；改了 console.js 后要跑 `node scripts/check_html.mjs` 并把 preview-app.js 同步镜像
